🧩 Chrome Extension — Gemini

Dịch, dịch lại đoạn trống và SEO chạy trên hồ sơ Chrome nào đã cài extension và đăng nhập Gemini — không cần Selenium hay geckodriver. Firefox/Selenium giữ làm dự phòng: extension không kết nối được thì ứng dụng tự mở Firefox.

Cài một lần

  1. Mở chrome://extensions, bật Developer mode (Chế độ nhà phát triển), chọn Load unpacked (Tải tiện ích đã giải nén).
  2. Chọn thư mục: {{ extension_dir }}.
  3. Đăng nhập Gemini trên hồ sơ Chrome đó. Extension tự bật với mã kết nối mặc định bên dưới — không phải dán gì.
  4. Bấm 🔌 Kiểm tra kết nối ở khối dưới; thấy ✅ thì về Home bấm Dịch như trước.

Mã kết nối extension KHÁC mã ?token= trong link trang web này. Dán nhầm mã web vào popup sẽ báo “Sai mã kết nối”. Bản extension 1.1.1 trở lên tự đổi về mã mặc định khi gặp lỗi đó.

Giữ Chrome và tab Gemini mở trong lúc chạy. Khi ứng dụng chưa chạy việc nào, popup extension báo “Đang chờ ứng dụng” là bình thường. Chỉ cài extension trên MỘT hồ sơ Chrome. Sửa mã extension thì bấm Reload ở chrome://extensions. Thay đổi cách dịch ở Home chỉ áp dụng cho việc mới xếp hàng. Muốn tắt dự phòng Firefox: OMNI_GEMINI_EXTENSION_FALLBACK=0.

Thử extension

Lượt thử ép dùng extension (không dự phòng Firefox), mở chat Gemini mới, không ghi file nào. Đang có phiên dịch thật chạy thì cổng bận — thử sau.
